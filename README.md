# POTENTIAL APPLE
 Megumi "Did you say potential" meme but Bad Apple.

## FAQ
"What is this made with?"
> The Godot 4 Game Engine.

"Why Godot?"
> Wanted to give it a go since I am learning it. Also I thought it'd be funny.

"Is this free?"
> Yes. Apache 2.0 license.

"How did you make this?"
> Aside from what is inside the repo, I used FFMPEG to extract every frame from Bad Apple, then used ascii-image-converter and a bash loop to batch convert every file.

"Did you use AI?"
> Nope.

## Open Source tools used
[Godot 4](https://godotengine.org/)

[FFMPEG](https://ffmpeg.org/)

[yt-dlp](https://github.com/yt-dlp/yt-dlp)

[ascii-image-converter](https://github.com/TheZoraiz/ascii-image-converter)
